# 高中化学实验室安全助手（修复版）

一个本地运行的化学实验室安全问答小工具：Flask + DeepSeek 流式对话，支持多轮历史、一键清空。

## 怎么用（三步）

1. **配置 API Key**（二选一）
   - 双击 `配置密钥.bat`，粘贴 `sk-` 开头的密钥，点击「写入并生效」；
   - 或者启动后，在网页右上角点「设置密钥」直接填写（密钥会写入本目录的 `.env` 文件）。
   - 密钥在 https://platform.deepseek.com 创建。

2. **启动**
   双击 `启动.bat`。程序会自动打开浏览器并访问 http://127.0.0.1:5000/
   黑色命令行窗口不要关，关掉即停止服务。

3. **提问**
   例如「浓硫酸溅到手上怎么处理」「高锰酸钾能不能和甘油放一起」「氢氧化钠怎么存放」。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `app.py` | 后端服务：页面、流式对话、历史读写、密钥读写 |
| `add_apikey.py` | 图形界面，把密钥写入当前用户的环境变量 `DEEPSEEK_API_KEY` |
| `tishici.json` | 系统提示词（角色设定、回答结构、拒答规则），改完在网页刷新即可生效 |
| `templates/index.html` | 网页界面 |
| `history.json` | 对话历史，删掉或清空即重置 |
| `requirements.txt` | 依赖：flask、openai |
| `启动.bat` / `配置密钥.bat` | 一键启动 / 一键配置密钥 |

## 常见问题

- **提示「尚未配置 API Key」**：按上面第 1 步配置；`配置密钥.bat` 写入的是用户环境变量，需要关掉已打开的程序再启动才生效。
- **提示「API Key 无效或已失效」**：密钥填错了或已删除，重新填一次。
- **提示端口被占用**：先关掉占用 5000 端口的程序，或在命令行里 `set PORT=5001` 后运行 `python app.py`。
- **想用手机 / 别的电脑访问**：`set HOST=0.0.0.0` 后再启动，用本机内网 IP 访问（首次会弹防火墙提示，需允许）。
- **想换模型**：`set DEEPSEEK_MODEL=deepseek-chat`（默认），也可试 `deepseek-reasoner`。
- **缺少依赖**：命令行执行 `python -m pip install -r requirements.txt`。

## 本次修复内容（相对原始代码）

1. `app.py` 模型名 `deepseek-flash` 在 DeepSeek 官方接口不存在，改为 `deepseek-chat`（可用 `DEEPSEEK_MODEL` 覆盖），否则每次请求都会报模型错误。
2. API Key 默认值 `"apikey"` 是占位符，必然 401。改为：识别占位符/过短密钥，未配置时给出明确中文提示，并支持网页内填写密钥（写入 `.env`）。
3. 客户端改为按密钥惰性创建，填写密钥后无需重启服务即可生效。
4. 补齐错误处理：密钥无效、限流/余额不足、超时、断网、参数错误全部翻译成中文提示，不再把原始异常抛到前端。
5. 历史裁剪按「一问一答」成对进行，并保证首条是 user，避免上下文被切坏后接口报 400。
6. 历史写入改为先写临时文件再替换，避免写入中断导致 `history.json` 损坏。
7. 历史读取增加字段校验，`.env` / 文件统一用 `utf-8-sig`，兼容记事本保存的带 BOM 文件。
8. 中文日志在 Windows 控制台的 `UnicodeEncodeError` 处理；启动后自动打开浏览器。
9. `add_apikey.py`：变量名拼写错误 `DEEPSEE_API_KEY` → `DEEPSEEK_API_KEY`（原来写进去的变量名程序根本读不到）；`tk.Tk(1)` 参数错误改为 `tk.Tk()`；去掉无意义的 `class Key:1`；增加密钥格式校验与写入后刷新环境变量。
10. 前端：增加密钥设置弹窗、未配置提示、请求体超长保护、SSE 解析兼容单事件多行、503 时自动引导配置密钥。
11. 新增 `启动.bat`（自动寻找装有 flask/openai 的 Python）、`配置密钥.bat`、`requirements.txt`、本说明。批处理使用 GBK 编码，避免中文乱码。
